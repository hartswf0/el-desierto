ABC-FLIX

OPERATIONAL MEDIA FORENSICS SUITE — EL DESIERTO / TROUTOWN PRODUCTION PIPELINE

A zero-dependency browser instrument suite for forensic video extraction, pixel-precision cropping, temporal analysis, and episodic assembly. Each tool is a single HTML file. No npm. No build step. Text operates as a physical control surface. Every sentence functions like a slip of paper.

THE PROBLEM CONTEXT

OPERATIONAL SITUATION

SOURCE:Sora generates 10–20s video loops viewed on a mobile device and screen-captured via Android.
ARTIFACT:648×1440 MP4 files containing: status bar (top 160px), home indicator (bottom 167px), variable-length recording noise, looped generative content, and embedded audio.
FAILURE:Frame-matching finds loops, not heads. When dialogue or ambient audio is present, the visual loop boundary ≠ the narrative start. The auto-detector lands on the tail.
CONSTRAINT:82 clips must be trimmed to ~10s each, cropped identically, normalized to 30fps, and assembled into 8 episodes of 60s each + a 13:46 full reel.

KEY INSIGHT

The audio waveform is the reliable signal. The first energy trough after initial recording noise (typically at 4–6s) marks the true head of the Sora content. Visual similarity confirms loop period; audio confirms narrative entry. The operator must be in the loop — tactile editing over heuristic automation.

THEORY OF THE PROGRAM NAURIAN

ENTITIES

<clip>A screen-captured Sora video. Has: id, duration, fps, frame_count, thumbs[], timestamps[], matrix[][], auto{in, out, period, confidence}.
<crop>Four-edge pixel inset {top, bottom, left, right}. Invariant: top+bottom < height, left+right < width.
<trim>Temporal window {in, out} in seconds. Defines the narrative segment.
<command>An ffmpeg invocation string. Derived surface — always computed from clip+crop+trim state.
<assembly>An ordered list of trimmed+cropped+normalized clips concatenated into an episode.

OPERATIONS

[detect]Self-similarity matrix + audio waveform → candidate IN/OUT points.
[inspect]Operator scrubs video, reads waveform, compares frames → confirms or overrides IN/OUT.
[crop]Edge-zoom magnification → operator sets pixel-exact boundaries → ffmpeg crop filter.
[normalize]Re-encode all clips to fixed 30fps + AAC audio. Eliminates VFR timestamp drift.
[assemble]Concat-demux normalized clips by episode manifest → final .mp4 files.

INVARIANTS

I1:Crop values are uniform across all 82 clips (TOP=160, BOT=167, LEFT=0, RIGHT=0).
I2:Output dimensions are always 648×1113 after crop.
I3:All assembled clips must be 30fps before concat — no VFR sources.
I4:The ffmpeg command displayed is always the ground truth. UI ↔ command ↔ pixel values form a bidirectional binding.

STAGE 4 — BATCH TRIM + CROP

SCRIPT:batch_trim_cropped.sh — generated from trim_manifest.json + confirmed crop values.
RUNS:82 ffmpeg commands, one per clip. Each applies temporal trim (IN→OUT) and spatial crop simultaneously.
# Example: Clip 001 ffmpeg -y -ss 5.25 -to 15.25 -i "SORA_CAPTURES/001_20260422_033154_screen_capture.mp4" \ -vf "crop=648:1113:0:160" "TROUT_TOWN_TRIMMED/001_20260422_033154_trim.mp4" # Example: Clip 003 (different IN point — head detected at 4.75s) ffmpeg -y -ss 4.75 -to 14.75 -i "SORA_CAPTURES/003_20260422_033514_screen_capture.mp4" \ -vf "crop=648:1113:0:160" "TROUT_TOWN_TRIMMED/003_20260422_033514_trim.mp4"
cd TROUT_TOWN_CONTACT_SHEETS/forensic_viewer && bash batch_trim_cropped.sh # [1/82] 001_20260422_033154 IN=5.25s OUT=15.25s # [2/82] 002_20260422_033331 IN=5.0s OUT=15.0s # ... # [82/82] 376_20260422_171302 IN=5.0s OUT=15.0s
OUTPUT:82 files in TROUT_TOWN_TRIMMED/ — each 648×1113, ~10s, still at source 120fps VFR.

STAGE 5 — NORMALIZE TO 30FPS

SCRIPT:normalize.sh
WHY:Source clips are 120fps VFR (variable frame rate). FFmpeg concat-demux requires identical frame rates. Without normalization, assembled episodes drift — a 60s episode becomes 47s or 83s due to timestamp misalignment.
cd TROUT_TOWN_TRIMMED && bash normalize.sh # Re-encodes each clip: ffmpeg -y -i "001_20260422_033154_trim.mp4" \ -r 30 -c:v libx264 -preset ultrafast -crf 22 \ -c:a aac -b:a 128k "norm/001_20260422_033154_trim.mp4"
BEFORE:001_20260422_033154_trim.mp4 — 648×1112, 120/1 fps, 10.042s
AFTER:norm/001_20260422_033154_trim.mp4 — 648×1112, 30/1 fps, 10.100s
OUTPUT:82 files in TROUT_TOWN_TRIMMED/norm/ — all fixed 30fps, AAC audio, ready for concat.

STAGE 6 — EPISODIC ASSEMBLY VIA CONCAT-DEMUX

SCRIPT:concat_clean.sh
METHOD:FFmpeg concat demuxer (-f concat -safe 0) — no re-encoding. Clips are stream-copied because they share identical codec, resolution, and frame rate after normalization.
cd TROUT_TOWN_ASSEMBLIES && bash concat_clean.sh

POML DESIGN CONSTRAINTS EPISTEMOLOGY
CONTRAST: Absolute white and black palette. All mid-tones explicitly removed. No #888, no #ccc, no subtle grays. Maximize stark contrast.
DEPTH: No glassmorphism. Blurring backgrounds destroys high-fidelity information (pixel data, waveforms, zoom strips) passing underneath. Gradients preserve visual information density.
SPATIAL: No PREV/NEXT pagination. Maximum vertical space for content. Navigation via spine dots and keyboard.
PERSPECTIVE: Camera anchors at the foot/base where the crop line meets the frame. Edge zooms show the strip extending away from the cut, not centered on it.
INTERACTION: Bidirectional binding enforced. Editing crop=W:H:X:Y in the command textarea updates the visual overlay. Dragging a handle updates the command. Text IS the control surface.
OUTPUT: The ffmpeg command is the ground truth. Every UI element derives from or writes to the command string.
WITTGENSTEIN: The meaning of a word is its USE in the language. The meaning of a crop value is its use in the ffmpeg command. The meaning of a waveform trough is its use in finding the narrative head. No metaphors. No abstractions. Operational pragmatism.
